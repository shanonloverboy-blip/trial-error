# Coding Xplor website

Static one-page site (plain HTML + CSS, no build step).

- `index.html` — the homepage (Bahasa Indonesia)
- `logo.png` — Coding Xplor logo
- `favicon.png` — browser tab icon

Deploy: push this folder to a GitHub repo and import it in Vercel
(Framework preset: "Other", no build command, output directory: `.`).
